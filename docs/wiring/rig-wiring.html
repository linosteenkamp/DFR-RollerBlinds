Gearbox Test Rig Wiring

The full wiring of the rig board. The rig uses the same XIAO, driver and power chain as the blind. It adds the driver UART, an AS5600 encoder, a DS18B20 temperature sensor and a KW11-2 top limit switch. The pin map comes from the spec (issue #27).

Change the present test board

The present test board has the XIAO, the TMC2209, the buck and J1. It does not need a change for the first rig firmware (ticket #31). Do these steps before the tickets that use the new parts.

  1. Disconnect the 24 V supply and the USB cable.
  2. Install the 1N5822 between the buck 5 V output and the XIAO 5V pin. Put the band toward the XIAO.
  3. Make sure that the 220 µF capacitor is at the VM pin. The stripe goes to GND.
  4. Make sure that MS1 and MS2 connect to GND.
  5. Install the 1 kΩ from D10 to the first PDN pin. Connect D0 to the same pin. Do not bridge the R10 pads.
  6. If the board has the keypad RC filter on D3 to D5, remove the 100 nF capacitors on D4 and D5. They make the I²C edges too slow. The 4.7 kΩ pull-ups on D4 and D5 can stay, because I²C needs them. The filter on D3 can stay for the limit switch.
  7. Install J2, J3 and J4, and the 4.7 kΩ pull-up on D1.

Checks before power

  1. Find the NC pin of the KW11-2 with a multimeter before you solder. NC has continuity to COM when the lever is free.
  2. Measure D3 to GND with the switch connected and the lever free. Expect 0 Ω, or 150 Ω if D3 has the keypad RC filter. Push the lever. Expect an open circuit.
  3. Measure the coil resistance of each motor at its cable end. Identify the two pairs.
  4. Set Vref to 1.92 V for the two units. The firmware sets the current of each unit through IRUN (ticket #33).
  5. Supply only 24 V. Measure approximately 4.6 V on the XIAO 5V pin. Then supply only USB. Measure approximately 0 V on VM.
